# 手机照片按钮：交流级待回复判定修复

日期：2026-10-11。范围：用户确认的“部分角色手机照片按钮无法点击”。用户已撤回“确认生成无法生图”的故障描述，本批不修改供应商请求。

## 原因与修复

回信队列的旧失败批次仍属于会话；照片按钮此前使用整个会话的待回复标志。即使新一轮交流已完整回复，旧失败也会持续禁用照片按钮。

- 队列支持按玩家消息 ID 查询待回复状态，同时保留原有会话级查询接口。
- 排队、失败待重试、正在生成或逐条展示的消息都保留请求身份，避免最后一个气泡出现时提前解锁。
- 照片按钮仅检查最新玩家交流；旧批次仍可独立重试，不删除旧错误或伪造回复完成。
- 无队列时保留失败标志的保守限制。已有回复清单、角色有效性、正在输入、照片消费与切档校验不变。
- 禁用原因在按钮下方可见，避免只能悬停查看说明。

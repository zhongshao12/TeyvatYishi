# 剧情资料来源与更新

内置剧情采用 v4 轻量存档：未编辑字段随资源更新；手工校订或 AI 重分解过的字段作为本地覆盖保留，当前篇章、分段、场景完成记录与历史进度独立保存。

在剧情编织面板选择系列与分段，可看到字段来源。旧档没有可靠来源指纹时，显示“旧档保留，来源未确认”，这是保守保留差异，不代表这些内容一定由玩家编辑。

点击某一行“恢复此字段内置值”，只撤销该字段的覆盖，不重置整个系列或当前进度；以后它跟随资源更新。其他本地校订继续保留。明确空字符串、空列表也是有效校订。

保存失败会显示错误并保留草稿；不要把失败提示当成已经落盘。保存期间游戏推进会重读并合并活体进度；切档后的迟到编辑不得提交到新档。

已载入游戏的剧情设置缓存按本次进程与会话隔离，实际读档来源是该档保存的剧情数据；启动剧情库仍兼容原设置键。迟到写入旧会话缓存不会覆盖新会话缓存。恢复同一字段内置值前，即使资源某一版本恰巧与玩家值相同，也继续保留编辑来源。

已移除的资源按 ID 保留本地资料与运行引用；旧轻量档未保存的正文显示资源不可用，不借用同名系列。自制剧情继续完整保存。JSON 备份与恢复保留来源信息，不以玩家姓名建立全局覆盖表。

维护者只修改 public/data/story-weaving-canon 的资源。总表通过生成器显式 --write 更新；--check 和完整回归只校验，不重写资源。指纹仅用于变化检测，不是安全签名。

# v1.6.0：手账手机与稳定性修复

日期：2026-10-13。

## 玩家能看到的变化

元素与天赋现在在同一页；原天赋菜单位置改为手机，左侧不再重复放手机入口。手机采用手账融合风格，分为消息、通讯录和朋友圈。

朋友圈先写草稿再发布，支持 500 字、最多 9 张图片和按身份点名。草稿、编辑及手机照片预览都有独立滚动区域和固定操作按钮。普通照片只取玩家要求及公开人物外貌，不发送关系数值、记忆或私密档案。

生图事实保护贯穿最终发送：记录的外貌放不下时，会明确拒绝请求，不能先收费再静默删字段。相册记录实际发送内容。预览期间改了人物资料，需要刷新草稿；读档保留人物视觉锚点。

故事预览关闭的角色不再参与英文翻译或发送其自动外貌块；手写场景文字不会按人名粗暴删除。NovelAI 的已记录事实保留完整英文拼写，包括带重音的姓名和含 `API` 字样的服装。通讯录跳转会展示选中的会话，草稿跟随实际收件人；手机关闭或载入期间仍能点击退出。

- GitHub 自动源码包：用于开发，按 README 安装依赖并运行。

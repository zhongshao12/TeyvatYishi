# 蒸汽鸟报独立 AI 与公开事实边界设计

状态：用户已确认设计；实施计划待审阅，尚未接入真实独立模型。

## 目标与已确认选择

用户选择真正调用蒸汽鸟报独立模型，只使用已确认公开的事件。修复 B20 的设置/实现不一致与 B21 的私密信息输入风险；不把完整正文或玩家输入改名为 publicFacts 后直接投递。

## 输入边界

新增可验证的公开事实记录，包含事实 ID、对应回合/结算 ID、世界时刻、公开渠道、正文证据及确认方式。公开渠道限定公开公告、已公开报道、面向公众的事件/演说，或玩家明确确认可公开的事实。

正文模型的事实候选本身不等于确认公开。无公开证据、可见性未知或只对少数角色可见的内容不入报纸；图书馆私谈、手机私聊、普通群聊、亲密档案、内心独白、未执行计划都不得输入报纸模型。公开地点也不等于该地点发生的所有谈话公开。

自动确认只接受同一条证据明确表明向公众宣布/公开发生的事实，并记录证据出处。证据矛盾或含混时留作未确认；玩家可以在报纸页确认其公开范围。不能由第二个模型自行扩大公开范围。

## 生成链路

1. 保留既有 enabled/autoGenerate/间隔设置；到期时只取最近间隔内确认公开且尚未报道的事实。没有可刊载事实时不调用模型，显示跳过原因。
2. 使用蒸汽鸟报专属 API 覆盖配置，未配置时按现有独立子系统的解析规则继承主 API；无有效配置则报告可重试失败。
3. 请求仅包含选中的公开事实、世界时刻与报纸专属提示词模块。禁止根状态、原始完整正文、私聊、角色私密档案、API 密钥进入内容提示词。
4. 生成简短报道，不复制原文；标题最多 40 字，导语最多 180 字，正文最多 600 字。报道必须引用输入事实 ID，不允许引用未知 ID 或新造事实。
5. 校验 JSON、字段与来源映射后生成本地稳定文章 ID。世界时间来自已提交时刻，createdAt/updatedAt 仍是传输时间。文章保存来源事实 ID，正常、重试与恢复共用同一个幂等键。
6. 失败不伪装成本地生成成功，不覆盖已存在报道；统一进入失败结算中心，并保留重试时的原公开事实与世界时刻。

## 正常、开局、恢复与重试

这四个入口调用同一任务接口，返回 success/skipped/failed 和提交增量。生成期间切档就丢弃迟到结果；同档新增文章或修改文章不能被旧快照整体覆盖。重试只处理当时冻结的公开事实，不重新扫当前完整正文。

因已刊载文章的旧格式没有来源证明，不能回溯宣称已通过隐私校验，也不擅自删除既有文章。界面提示旧文章来源未校验；新模型请求不再次输入它们的全文。

## 界面一致性

连接测试使用实际独立模型出口，显示连接、接收和校验阶段，并可取消。报纸任务显示是否到期、有多少确认公开事实、调用成功/失败；不再在本地摘句路径显示“正在调用独立 API”。新报道支持来源详情与确认入口；明确标注模型生成，不能承诺绝对没有幻觉。

## 验收

- 私聊、私密接触、未知可见性、仅玩家读到的旁白不进入请求；公开公告与玩家明确确认的事实可以进入。
- 使用假 API 检查请求实际走独立配置；仅注入报纸适用提示词模块，不带全文或根状态。
- 不到期/无公开事实时调用数为零；正常生成确实调用一次，而不是本地摘句。
- 正常与恢复、重复重试不会重复报道；切档、并发编辑、部分非法来源均不污染文章状态。
- API 400、正文超时、取消、解析失败均保留原文章并进入可重试失败记录；成功后清除对应失败状态。
- 长输出不能从句中粗暴截断伪装成功；超长结果要求模型修正或校验失败，界面给出原因。

## 不在本次范围

不把报纸内容强制广播给全部 NPC，不给未知事件自动授予全员知情，不改变 B08/B09，不自动删除历史报道，不增加发送硬上限。书面设计审阅通过后再写实施计划。

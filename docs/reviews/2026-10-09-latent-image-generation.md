# 生图修复与 Latent 接入

## 使用方式

1. 打开设置 → 文生图 → 统一接口，选择 **Latent（浏览器兼容接口）**。
2. Base URL 自动填写 `https://latent.moe`，预设路径为 `/api/novelai/ai/generate-image`。
3. 在本地设置中填写自己的 Designer API Key（`lat_sk_…`），启用接口与文生图总开关，保存设置。
4. 在相册生成头像、立绘或场景；正文快照仍使用统一接口，生成结果仍进入本地游戏相册。

切换到 Latent 时会清空其他供应商的密钥与模型，防止误发送；从 Latent 切换出去同样清空这两项及地址，需要重新填写目标供应商配置。不会更改另一套独立接口的设置。

## 接入边界

- 使用官方支持跨域的 NovelAI 兼容接口，不嵌入生成网页，不依赖浏览器登录 Cookie，不上传图片到公开画廊。
- 服务端固定模型、固定 CFG；界面显示只读说明，不提供无效的模型选择、响应格式或 CFG 调整。
- 支持方形 1024×1024、竖图 920×1536、横图 1536×920；其他请求尺寸按方向映射。相册记录映射后的提供尺寸。
- 步数限制为 8–12；Seed 0 可以使用，负值代表随机。
- 不支持参考图和 V4 多角色定位。已启用角色的外貌描述与负面描述合并进主提示词，已有扩写中的完整片段不会重复添加；不拆散带权重的逗号短语。
- 正、负提示词各最多 2000 字符；2026-10-10 已改为生成草稿自动精简、最终合并后再次精简，保留角色辨识特征并记录实际发送文本，详见 `2026-10-10-image-prompt-auto-compaction.md`。
- 当前页面的全部 Latent 入口共用串行队列。接口失败不自动重试，防止服务器已接收任务后重复消费额度。

## 取消、超时与恢复

Latent 官方说明：断开客户端请求不会取消服务器任务。运行中取消、网络错误、正文读取超时或 5xx 后，原任务可能继续生成。

- 排队中的本地请求可立即取消，稍后也不会提交该请求。
- 请求及正文读取超过 180 秒会中止本地等待。
- 无法确认服务器任务结束时，暂停同一端点与密钥的后续提交，排队请求也不会继续发送。
- 检查 Latent 控制台，确认没有运行中的任务后，在接口设置点击 **已检查控制台，恢复生成**。该按钮仅解除本地暂停，不发起生成，也不找回原任务的图片。
- 连通性测试只发 OPTIONS，不消耗生图额度；成功不代表密钥、额度或生成能力已验证。

暂停标记只保留在当前页面内，以端点和密钥识别；不跨窗口、刷新、其他密钥或网站自身的任务。服务端仍是账号并发约束的最终执行者。该兼容接口不提供客户端任务 ID，本批不接入原生任务查询、取消和恢复接口。

## 修复的三个问题

1. NovelAI OPTIONS 返回 404 不再被当成连接成功，成功提示明确区分连通性和鉴权验证。
2. 二进制响应、下载图片和 ZIP 内图片检查图片签名，HTML、空响应或不匹配的内容不再冒充成功图片。未扩展为所有格式的完整解码验证。
3. ComfyUI 工作流的字符串占位符经过 JSON 转义后一次替换，双引号、反斜线、换行不再破坏 JSON；原有数字占位符仍兼容。

独立代码复核还发现并修复了场景描述重复导致误判超限、未知任务之后继续提交以及排队取消不立即返回的边界问题。

# 手机与相册共享生图提示词库

## 实施边界

用户已确认这是现有生图编辑流程的有界扩展；依据 brainstorming 的有界路径直接实施，不新增生图后端、API 调度器、游戏状态字段或数据库结构。

- 手机照片预览、相册图片生成、故事快照、场景图、手机背景共用同一个词组组件。
- 17 组内置词组：日式西幻、温暖手账、质量修正、头像/生活照片/宽幅构图，以及蒙德至至冬、须弥沙漠、龙脊雪山、层岩巨渊。
- 分类、搜索、正负预览；可分别追加正面、负面或两者。只去除追加部分的重复片段，不改写原有角色资料、玩家要求或权重语法。
- 自定义词组可新增、编辑、确认删除；持久化到现有本地设置的独立键 `imagePromptLibrary`，手机和相册共享。读取失败时禁止覆盖未知内容；保存失败保留编辑表单，成功落盘后才发布更新。
- 故事快照同时追加到实际使用的分层场景正负提示词，不修改角色分层。
- 选择词组不调用模型；确认生成才进入原有图片接口。继续使用现有精简、清洗和后端长度限制。

## 使用方法

先生成或编辑提示词，再展开“生图提示词库 · 快速选词”，选择分类或搜索词组，查看正负预览后追加，最后确认生成。相册会打开高级编辑区以便检查结果。

词组只作用于当前草稿：再次“更新/生成提示词”会重新构建草稿，需重新追加。这一行为与既有手动编辑一致，界面已明确提示；自定义词组本身不会被重建草稿删除。内置词组只读。

## 限制与保留

- 未调用真实付费生图接口，未访问真实玩家数据库；不能据此保证每个供应商的实际图片质量。
- 本地词组持久化通过合成适配器的读写/重载验证；真实 Windows 桌面重启与文件系统故障仍需真实设备验收。
- 既有四个未提交手机文件及其报告保持原状，未混入此提交。保持当前 codex 分支，不合并 main、不推送。
- 验证日志与截图保留于本批专用临时目录；此前临时目录清理被安全策略阻止，不尝试绕过删除。

## 验证过程中处理的失败

- 初始组件缺失及实际入口缺失：按 TDD 实现并接入共享组件。
- 头像集成测试错误地选中了不存在的伙伴选项：补齐真实 fixture 的 `companion` 阶位，保留姓名与外貌断言；同名“生成”导航按钮改为选取工作区内末尾的生成按钮，不改产品判断。
- 测试 `findLast` 超出现有 ES2022 与狭窄 fixture 类型：使用反向 `find` 和正式状态类型，不更改项目编译目标。
- Windows 浏览器脚本绝对盘符导入被 Node 拒绝：只修测试脚本为标准 file URL，产品代码无变化。
- 新组件焦点 effect 的依赖警告：依赖稳定编辑 ID，不依赖每次输入变化的整个草稿；校验后无新增警告。

# 人物视觉资料与手机照片交付记录

日期：2026-10-10。范围为用户确认的相册人物资料补齐、手机预览确认后生成普通照片；不包含提交、合并或推送。

## 使用方法

1. 在设置启用文生图及普通图片接口，沿用已配置的供应商（包括 Latent）。
2. 在手机私聊或群聊中找到有对应 NPC 档案的角色回复，点击该消息下的“生成照片”。玩家可以先在聊天中提出拍照请求，再选择角色的回复。
3. 预览中显示真实角色身份和档案来源，可修改拍照描述、正面及负面提示词；“更新提示词”只在本地执行，不调用图片 API。
4. 点击“确认生成”才调用图片接口。成功后照片挂到所选角色消息，原消息文本保留，同时收入相册；点击图片可查看大图。已有照片的消息不再重复生成。
5. 失败会显示原因并保留编辑内容，可再次确认重试。关闭预览或手机会取消未完成任务。

## 实现边界

- 相册头像、场景、故事快照和手机共享人物视觉事实：姓名、性别、概括外貌、已记录的发色/瞳色/身高/体重及允许展示的外貌细项、常用穿着。缺失数值不自动编造；保留原资料来源标注。旅人档案的顶层身高也会保留。
- 角色锚点沿用启用与场景注入开关。可识别的锚点发色、瞳色优先；清除冲突颜色时保留同句的饰品、伤痕等细节。模型改写后仍补回已记录事实。
- 共用模型输出清理器覆盖词组转化器、故事快照（含逐角色描述）及相册场景解析，过滤没有对应记录的模型数值。校验同字段、规范单位别名及完整有序数值；例如体重 170 不代表身高 170，170 厘米不授权 170 英寸，三围也不能乱序或挪用另一部位的数值。不擅自换算单位，场景距离和门框描述保持不变。多人全局描述不盲目删除其他角色的颜色；可归属的快照角色描述分别检查。
- 本地草稿及手动提示词不走模型输出清理器。精简保护角色资料与适用锚点，沿用 1800 字符草稿预算；保护字段本身超限时明确提示，而不是静默丢弃。
- 相册头像、场景图和故事快照入口会捕获提示词整理失败，显示具体原因并保留原草稿、标题和解析结果，恢复解析按钮；只有整理成功才发布新结果。资料保护块超限时，可减少同框角色或在档案中缩短外貌摘要后重试。
- 普通手机照片只读取所选会话截至所选消息的有限聊天片段，限玩家与目标角色，不读取其他私聊或其他群成员的内容。不提供私密照片入口，不读取或发送 NSFW 档案的私密经历字段；既有外貌展示资格判断只在本地使用年龄确认信息。
- 手机仅保存 `entryId/assetId/npcId` 图片引用，不复制图片负载，不改变头像、好感度或同行记忆。群聊按所选消息的真实发言者生成，不通过同名猜测角色。
- 根状态事务同时提交照片和消息引用，并返回实际接受结果。切档、会话/消息删除、联系人改绑或不可用时拒绝迟到结果，避免半提交、串档和并发消息丢失。失败、取消、重试使用现有相册任务记录与生图队列。
- 将照片提交协调逻辑移入 `hooks/useCourierPhotoCommit.ts`，照片编辑面板按需载入；提示词转化器、快照和照片服务沿懒入口自然分包，没有放宽体积或模块行数门禁。

## 验证限制

- 生图网络出口使用受控替身测试；没有调用真实付费 API，因此不宣称验证了供应商实际耗时、计费或最终画面质量。
- 未执行真实手机键盘/移动设备验收或 Windows 桌面打包安装。
- 构建仍有既有 `failureCenterStore` 静态/动态混合导入提示及大 chunk 提示；体积门禁通过不代表这些提示已消失。
- Windows 默认临时目录曾导致 esbuild 清理权限错误，本次构建将 TEMP/TMP 指向项目 `.tmp-regression` 完成；没有删除用户临时文件。
- 保留当前分支与全部既有未提交改动，没有执行 Git 提交、合并、推送。
